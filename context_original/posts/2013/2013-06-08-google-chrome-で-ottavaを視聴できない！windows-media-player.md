クラシックの音楽ラジオ「Ottava」をよく視聴しています。
 [](http://ottava.jp/) [インターネットラジオ | OTTAVA by TBS](http://ottava.jp/)      
 
  
Windows での GoogleChromeで視聴しようとすると、Windows Media Playerのプラグインのインストールを求められます。けれども、インストールがうまくいかずに3年くらいずっとそんなものかと思っていました。今日は、ようやくGoogleChromeでもきくことができたので記事にします。
  
 
  
### Windows Media Player プラグインのインストール方法
  
まず、視聴しようとすると「Windows Media Playerが必要なコンテンツがあります。」というメッセージが出てきて、プラグインのインストールが求められます。
  
 
  
[](http://hmi-me.ciao.jp/everclassic/wp-content/uploads/skitch.png)
  
 
  
インストールサイトに飛んでDownlowdの「here」とかかれたところをクリックしてダウンロードします。
 [](http://www.interoperabilitybridges.com/wmp-extension-for-chrome) [Interoperability Bridges and Labs Center](http://www.interoperabilitybridges.com/wmp-extension-for-chrome)      
 
  
[](http://hmi-me.ciao.jp/everclassic/wp-content/uploads/skitch1.png)
  
 
  
   - wmpChrome.crx
 
        
これをそのまま実行しようとすると、「このウェブサイトから追加できません」というメッセージが現れます。
   [](http://hmi-me.ciao.jp/everclassic/wp-content/uploads/skitch2.png)  
 
  
Chromeツールバーから ツール -> 拡張設定 を選択。
  
この画面に、さきほどダウンロードしたvmpCrhome.crxをドラッグ & ドロップします。
  
これで、Windows Media Player プラグインがインストールされました。
